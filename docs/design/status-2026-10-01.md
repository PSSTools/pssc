## Next: operation-model gaps

These come from `tests/compliance/expected/op-model-py.toml` and
`op-model-sv.toml`. The `act.*` entries are out of scope: an operation-model
entry has no activity.

- **Entry shape** (`export_action.py`). An entry cannot be an action that
  reads its own attributes (`proc.field.rw.001`) or has `rand` attributes
  (`proc.rand.input.001`). Entries take no parameters yet.
- **op-model-py:**
  - range patterns in `match` (`ExprRange`, no `expr_range` hook):
    `proc.match.ranges.001`;
  - `PatternAs` is not lowered: `types.enum.match.001`;
  - blocking channel `get`/`put` need `--py-await async`, and DEPTH > 1 is
    rejected: `sync.channel.depth.001`.
- **op-model-py and op-model-sv.** A user function named
  `get_offset_of_instance` is taken for the `reg_group_c` built-in by name
  alone (`call_legality` / `_fold_offset`): `types.string.match.001`.
- **op-model-sv.** It has no executor delegation
  (`supports_executor_delegation`), so the four `L0P.tap.*` tests fail.
- **C backend.** Inheritance is flattened; the user wants a vtable (memory:
  op-model-c-vtable-super).

Suggested first step: survey these entries the way the bc plan did, then write
`docs/design/op-model-gaps-plan.md` with decisions for review.

## Known open defects

- **be-bc `select` draws alternate.** `SeedStream.next_below` is
  `lcg % n`, and the LCG's low bit alternates, so consecutive two-way selects
  alternate. Two strict xfails record it in
  `tests/unit/integration/test_activity_symbols.py`. The fix needs a
  determinism/ABI version bump and the same change in rt-eng. It is deferred;
  the user has not decided.
- **The front end does not specialize struct templates.** The `TRAIT trait`
  field of `addr_region_s<>` reaches the IR as `DataTypeRef("TRAIT")`. bc holds
  it as an opaque slot and refuses any access to it. The fix belongs in
  ast2ir.
- **bc executors.** An executor outside the frame's component subtree is
  refused. So is a memory access from an action whose component type has more
  than one instance.
- **Blocking channel `get`/`put` on bc** spin on a SPIN yield. The user wants
  an event form; it is temporary.
- **`L.h.val`** (a path through a labeled block) reaches bc as an unlocated
  `LoweringError`.
- **A handle declared in a base action** and traversed in a derived one is
  refused with a location.
- **rt-eng** refuses component state, channels, memory builtins and the P1
  activity ops until P8.
- **Failures that predate this work:** 4 doc-reference failures in
  `tests/unit`; 8 in `tests/progseq` (`test_call_legality`,
  `test_c_body_lowering`, `test_c_imports`); 13 sv-pure `std_pkg` simulation
  failures.
